# SCAHI – algorithm specification (exported from the code)

Generated by `scripts/scahi_algorithm_doc.py` from `scahi/infer/cache_mz.py`, `scahi/fusion/scalespace.py` (variant **F2**, the method of the paper) and `scahi/fusion/run.py`; parameter tables from the frozen configurations. Notation: image W × H px (original), one *stack* = a set of *levels*, a level = one or more *passes* (whole image or tiles). All coordinates are original-image px.

## 1. Passes and inputs

**Levels used in the paper.** A stack is `(whole-image pass at long side s, tiles at zoom z = 2 with network input N = 1024)`, e.g. `native2048` = (`w2048`, `t2.0n1024`). Overlap ρ = 0.3 for the tiles (also the border-taper width, Section 3).
- *Whole-image pass* at long side s: letterbox (aspect kept, centred, pad value 114) to an input of ceil(h·g/32)·32 × ceil(w·g/32)·32 with gain g = s / max(W, H).
- *Tiles* at zoom z, input N: tile side T = N / z original px (here 512); start positions along each axis 0, step, 2·step, … with step = round(T·(1 − ρ)), plus a last tile at L − T so that every tile has full size (SAHI convention); one whole-image tile if T ≥ max(W, H). Each tile is letterboxed to N on its long side (gain g_t = N / max(tile w, tile h)), padded to multiples of 32.
- *Network output per pass* (raw head, before any NMS or top-k; `scahi/infer/raw_head.py`): for every anchor a of the dense head, DFL box logits (4 sides × reg_max bins) and class logits. **Head:** the one-to-many (o2m) head for all SCAHI rows (YOLOv10: o2m branch; YOLOv11/v12: their only head).
- *Decoding* (`scahi/infer/dfl_decode.py`): per side, softmax over the reg_max bins → distance = expectation × stride, **std = sqrt(variance) × stride** (input px); box = anchor centre ± distances (xyxy, input px); class probabilities p_c = sigmoid(logit_c).
- *Raw cache* (`cache_mz.raw_predict_level`): anchors with max_c p_c ≥ 0.001 (`SCORE_MIN`) are kept, with box mapped to original px: x_orig = (x_in − pad_x) / g + tile offset (same for y), probabilities [n, nc], DFL std / g (original px), pass id. Per pass also the tile rectangle and its gain g.
- **DOTA v1.5 (horizontal boxes, nc = 16 classes).** Stacks `dota1024` / `dota2048` = (whole-image pass at s = 1024 / 2048, tiles at **native resolution** z = 1 with N = 1024, i.e. tile side T = 1024 px); overlap ρ = 0.3. Everything else (decoding, raw cache, Sections 2–7) is identical; the class vector has 16 entries (`fuse_image(..., nc=16)`).

## 2. Prediction table (per image, per stack)

For every cached anchor of every pass with **p_max = max_c p_c ≥ tau_splat**: centre (cx, cy), width and height w, h = max(x2 − x1, 1e-3), max(y2 − y1, 1e-3), size **σ = √(w·h)** (original px), log w, log h, class vector p ∈ [0, 1]^nc, pass id, level index k.

## 3. Weights (F2)

**Border taper b** of a prediction in tile t of level k, evaluated at its centre (cx, cy):
- raw ramp per tile: r_t(x, y) = Π over the tile's four edges that are **not** on the image border of sin²(π/2 · clip(d / (ρ·L_t), 0, 1)), with d the distance from (x, y) to that edge inside the tile and L_t the tile side along that axis; r_t = 0 outside the tile;
- normalised over the tiles of the same level: b = r_t(x, y) / Σ_t' r_t'(x, y) (0 where the sum is 0); whole-image passes: b = 1.
**Weight** w = b (F2). (The validity window in network-input size – raised cosine in log2 from 0 at 6 px via 0.5 at 8 to 1 at 14, flat to 192, down to 0 at 256 – and the DFL-uncertainty factor belong to the variants F3–F5, **not to F2**.)

## 4. Coverage (analytic, from geometry only)

C(x, y) = number of **levels** with at least one pass whose rectangle contains (x, y) (F2). For the stacks of the paper (whole image + tiles covering the image) C = 2 everywhere. C does not depend on the predictions.

## 5. Scale-space grid and splatting

- **Size axis:** σ-bin coordinate u(σ) = (log2(max(σ, σ0)) − log2 σ0) · β with σ0 = 2 px and β = `bins_per_oct`; bin j has centre size σ_j = σ0 · 2^((j + 0.5)/β).
- **Spatial cells of bin j:** square cells of side g_j = max(1, σ_j / κ) px (κ = `cell_factor`); cell (i_x, i_y) has centre ((i_x + 0.5)·g_j, (i_y + 0.5)·g_j).
- **Mass** of a prediction: m = w · p_max.
- **Trilinear splat:** in size, between bins j0 = floor(u − 0.5) and j0 + 1 with weights 1 − f and f, f = u − 0.5 − j0; in each of the two bins separately in space, bilinear onto the four cells around (cx/g_j − 0.5, cy/g_j − 0.5) (each bin with its own cell size g_j); bins j < 0 are dropped. Accumulated sparsely (hash of (j, i_x, i_y)): numerator N(j, i_x, i_y) = Σ m · weights.
- **Field** S = N / (C(cell centre) + ε), ε = 1e-06.

## 6. Peaks

- A cell is a peak if S ≥ **tau_peak** and S ≥ S of each of its 26 neighbours: offsets (Δj, Δx, Δy) ∈ {−1, 0, 1}³ \ 0, where the neighbour cell in bin j + Δj is the cell of that bin's grid containing the peak cell's centre, shifted by (Δx, Δy) cells; empty cells count as −∞ (ties allowed: ≥).
- Peaks sorted by S (descending); at most 2 · top_k = 1000 are processed.

## 7. Score and box per peak

In descending S order, for peak cell (J, centre x_c, y_c, size g_J):
1. **Members:** predictions whose rounded size bin round(u − 0.5) ∈ {J − 1, J, J + 1} and whose centre lies within Chebyshev distance 1.5 · g_J of (x_c, y_c).
2. **Strongest member** t = argmax over members of w · p_max. If t was already the strongest member of an earlier (stronger) peak, the peak is dropped (one detection per strongest prediction).
3. **IoU clustering:** keep members whose box has IoU ≥ **iou_cluster** (= 0.5) with the box of t (IoU without +1 convention).
4. **Class scores:** for each class c, per pass the maximum of w · p_c over the kept members of that pass, summed over passes, divided by C(peak) + ε. (A pass that covers the location but has no member contributes 0: negative evidence.)
5. **Box:** weights ω = w · p_max of the kept members; centre = ω-weighted mean of (cx, cy); width, height = exp of the ω-weighted mean of log w, log h.
6. **Classes per peak:** the 3 highest class scores > 0, each emitted as a detection with the same box.
7. Output: detections sorted by score, first top_k = 500 per image (VisDrone; DOTA: pipeline limit, Section 9); boxes clipped to the image (`run.clip_xywh`); no final NMS (`final_nms = False`).

## 8. Parameters

| parameter | symbol | meaning |
|---|---|---|
| tau_splat | τ_s | minimum p_max of a prediction to enter the field (Section 2) |
| tau_peak | τ_p | minimum field value of a peak (Section 6) |
| cell_factor | κ | spatial cell side g_j = max(1, σ_j / κ) |
| bins_per_oct | β | σ bins per octave |
| iou_cluster | – | member clustering threshold (fixed 0.5) |
| overlap | ρ | tile overlap and taper width (fixed 0.3) |

## 9. Complexity and implementation limits

- n = number of predictions above tau_splat. Splatting O(n) (8 cells each), sparse accumulation O(n log n) (sort of the cell keys), peak test O(M log M) for M occupied cells (26 lookups by binary search), members per peak by one k-d tree per σ bin. Memory O(n + M).
- Cell keys pack (j, i_x, i_y) into one int64 with b bits per spatial index (`key_bits`): b = 13 if max(W, H) + 2 ≤ 8191, else b = 15 (spatial indices clipped to 2^b − 1 cells of ≥ 1 px). VisDrone images (≤ 2000 px) always use 13 bits, so VisDrone results are unchanged; DOTA images (long side up to 13 383 px) use 15 bits (32 767 cells per axis); j uses the remaining 64 − 2b bits.
- Output limit per image: top_k = 500 (VisDrone evaluation cap). DOTA: the pipeline limit replaces top_k (the same limit per pass for box fusion): 20000 on calib (parameter selection) and 200000 on DOTA-val; the primary metric has no cap, a cap of 4000 per image is a secondary metric.

## 10. Pseudocode

```text
input: passes P (whole image at s; tiles z=2, N=1024, overlap ρ), params τs, τp, κ, β
for each pass π in P:  raw = dense_head(letterbox(crop_π)); decode DFL -> boxes, p, std; map to image px
Pred = {a : max_c p_a,c ≥ τs}; for a in Pred: w_a = taper_π(a.centre); m_a = w_a · max_c p_a,c
for a in Pred: splat m_a trilinearly into cells (j, ix, iy) of the (log σ, x, y) grid  [g_j = max(1, σ_j/κ)]
S(cell) = N(cell) / (C(cell) + ε)          # C = number of levels covering the cell centre
peaks = cells with S ≥ τp and S ≥ all 26 neighbours, sorted by S desc, first 2·top_k
used = {}
for peak in peaks:
    M = preds with |bin−J| ≤ 1 and Chebyshev dist(centre, peak) ≤ 1.5 g_J
    t = argmax_{a∈M} m_a; if t ∈ used: continue; used ∪= {t}
    M = {a ∈ M : IoU(box_a, box_t) ≥ 0.5}
    score_c = Σ_π max_{a∈M∩π} w_a p_a,c / (C(peak) + ε)
    box = (ω-mean cx, ω-mean cy, exp ω-mean log w, exp ω-mean log h), ω = m
    emit (box, c, score_c) for the 3 best classes with score_c > 0
return top_k detections by score, clipped to the image
```
